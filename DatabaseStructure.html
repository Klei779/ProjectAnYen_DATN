17. thongbao - Thông báo
Column Name Type Description
MaThongBao Integer (PK, Auto) Mã thông báo
TieuDe String Tiêu đề
NoiDung TEXT Nội dung
LoaiThongBao String Loại thông báo
NguoiGuiId Integer ID người gửi (nhân viên)
NguoiNhanId Integer ID người nhận (nhân viên)
MaKhachHang Integer Mã khách hàng
TrangThai Integer Trạng thái
LyDoTuChoi TEXT Lý do từ chối
NgayTao LocalDateTime Ngày tạo (auto)
NgayCapNhat LocalDateTime Ngày cập nhật (auto)
Loại thông báo:
- CONG_VIEC: Thông báo công việc (có nút Chấp nhận / Từ chối)
- HE_THONG: Thông báo hệ thống (chỉ đọc)
- TU_CHOI: Phản hồi từ chối gửi về hotline
- DUYET_SAN_PHAM: Thông báo duyệt sản phẩm mới từ đối tác
Trạng thái:
- CHUA_DOC: Chưa đọc
- DA_DOC: Đã đọc
- DA_CHAP_NHAN: Đã chấp nhận
- DA_TU_CHOI: Đã từ chối
- CHO_XAC_NHAN: Chờ nhân viên duyệt sản phẩm
